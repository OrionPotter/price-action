# K线形态详细参考

## 一、趋势棒（Trend Bar）

### 多头趋势棒
```
特征：
│  ←上影线极短或无
█  ←大实体阳线（收盘近最高）
│  ←下影线短（不超过实体1/3）

判断标准：
- 实体 > K线总高度的 60%
- 收盘价在K线总范围上半部分
- 实体颜色为阳（收 > 开）

含义：买方压倒性控制，强烈看涨信号
```

### 空头趋势棒
```
特征：
│  ←上影线短（不超过实体1/3）
█  ←大实体阴线（收盘近最低）
│  ←下影线极短或无

判断标准：
- 实体 > K线总高度的 60%
- 收盘价在K线总范围下半部分
- 实体颜色为阴（收 < 开）

含义：卖方压倒性控制，强烈看跌信号
```

## 二、信号棒（Signal Bar）

### 多头信号棒（做多信号）
```
特征：
 │   ←上影线短
 █   ←小/中实体（阳或阴均可）
 │   ←下影线长（超过实体1倍以上）
 │

判断标准：
- 下影线 > 实体长度
- 通常在支撑位/区间下沿出现
- 可以是阳线或阴线（阳线更强）

含义：下方遭遇强买盘，价格被推高，看多
```

### 空头信号棒（做空信号）
```
特征：
 │   ←上影线长（超过实体1倍以上）
 │
 █   ←小/中实体（阴或阳均可）
 │   ←下影线短

判断标准：
- 上影线 > 实体长度
- 通常在阻力位/区间上沿出现
- 可以是阴线或阳线（阴线更强）

含义：上方遭遇强卖盘，价格被压低，看空
```

### 失败信号棒
```
场景：出现信号棒后，价格反向突破信号棒极值

多头信号棒失败 → 看跌反转（比普通空头信号更强）
空头信号棒失败 → 看涨反转（比普通多头信号更强）

原因：信号棒后反向说明假信号，被套的交易者被迫出局
```

## 三、特殊形态

### 外包柱（Outside Bar / OB）
```
前K:   ┌─┐
       │ │
       └─┘

当K:  ┌───┐  ← 最高点高于前K最高
      │   │
      └───┘  ← 最低点低于前K最低

判断：当前K线完全"吞噬"前一根K线
含义：
- 出现在区间底部 → 多头外包（看多）
- 出现在区间顶部 → 空头外包（看空）
- 出现在趋势中 → 可能加速或反转，需结合位置判断
- 实体大且无影线 → 趋势棒外包，信号极强
```

### 内包柱（Inside Bar / IB）
```
前K:  ┌───┐
      │   │
      └───┘

当K:   ┌─┐  ← 最高点低于前K最高
       │ │
       └─┘  ← 最低点高于前K最低

判断：当前K线完全在前一根K线范围内
含义：
- 多空均衡，能量积聚
- 突破内包柱高点 → 做多信号
- 跌破内包柱低点 → 做空信号
- 通道中的内包柱：顺趋势方向更可靠
```

### 十字星（Doji）
```
形态：
  │   ←上影线
  ─   ←极小实体（开=收或接近）
  │   ←下影线

变体：
- 普通十字星：上下影线均衡
- 蜻蜓十字：长下影线，无上影线（看多）
- 墓碑十字：长上影线，无下影线（看空）
- 四价十字：开高低收全相等（极度平衡）

含义：多空完全平衡，需等待方向选择
```

### 孕线（Harami）
```
孕线 = 内包柱的K线组合形式（两根K合看）

多头孕线：大阴线 + 小阳线（孕在阴线内）
空头孕线：大阳线 + 小阴线（孕在阳线内）

注意：孕线本身只是警示，需要第三根K确认方向
```

## 四、组合形态

### 吞噬形态（Engulfing）
```
多头吞噬：
前K: ┌─┐（阴线）
当K: ┌───┐（阳线，完全吞噬前K实体）

空头吞噬：
前K: ┌───┐（阳线）
当K: ┌─┐（阴线，完全吞噬前K实体）

强度：外包柱吞噬 > 实体吞噬 > 部分吞噬
```

### 连续趋势棒（Consecutive Trend Bars）
```
3根以上连续同向趋势棒：

多头连续趋势棒（强多）：
█  █  █  ← 连续阳线，每根都更高

空头连续趋势棒（强空）：
█  █  █  ← 连续阴线，每根都更低

含义：
- 3根以上：趋势极强，不要逆势
- 通常出现在突破或通道加速阶段
```

## 五、K线强度评分

| 评分 | 特征 | 操作参考 |
|------|------|----------|
| ★★★★★ | 大实体趋势棒，无影线 | 强信号，可积极入场 |
| ★★★★ | 大实体，影线短 | 可靠信号，常规入场 |
| ★★★ | 中等实体，影线中等 | 需额外确认 |
| ★★ | 小实体，影线较长 | 等待下一根确认 |
| ★ | 极小实体或十字星 | 不确定，观望 |

## 六、位置判断（Context Matters）

**同样的K线，位置不同含义不同！**

| K线形态 | 出现在区间下沿 | 出现在区间中部 | 出现在区间上沿 |
|---------|---------------|---------------|---------------|
| 多头趋势棒 | 强多头信号 ✅ | 可能继续上涨，但需谨慎 | 可能假突破 ⚠️ |
| 空头趋势棒 | 可能假突破 ⚠️ | 可能继续下跌，但需谨慎 | 强空头信号 ✅ |
| 长下影线 | 强支撑反弹 ✅ | 参考意义较弱 | 暗示上方阻力 |
| 长上影线 | 暗示下方支撑 | 参考意义较弱 | 强阻力压制 ✅ |

**原则：永远先看位置，再看形态。**
