# 量价分析参考

## 核心原则

量价配合是验证价格行为信号的辅助工具，不单独使用。
A股使用成交额（amount）比成交量更可靠，避免高低价股不可比问题。

**分析顺序：先看价格结构 → 再用量价验证 → 最后决策。**

---

## 一、突破确认

### 有效突破的量价特征

| 特征 | 说明 |
|------|------|
| 突破K放量 | 成交额 > 近5日平均成交额 × 1.5 |
| 跟随K维持量能 | 跟随K成交额不低于突破K的 70% |
| 换手率提升 | 换手率明显超过近5日平均水平 |
| 缺口不回补 | 跳空突破伴随放量，缺口当日不回补 |

### 假突破的量价特征

| 特征 | 说明 |
|------|------|
| 缩量突破 | 突破K成交额未明显放大（< 近5日平均 × 1.2） |
| 突破后缩量 | 突破后立刻缩量回落 |
| 放量滞涨 | 换手率极高（> 近5日平均 × 3）但涨幅有限 |
| 长影线 | 突破K带长上影线（阻力强） |

## 二、量价背离

### 顶部背离（看空警示）

```
价格创新高，但成交额低于前一次创新高时的成交额
含义：上涨动能衰减，买盘力量不足，可能见顶
操作：A股不做空，但应减仓或设紧止损
特别注意：三推上涨 + 量价背离 = 高概率反转信号
```

### 底部背离（看多信号）

```
价格创新低，但成交额低于前一次创新低时的成交额
含义：卖压衰减，空方力竭
操作：等待多头信号棒出现后入场做多
注意：底部背离单独出现仅为警示，需配合信号K确认
```

## 三、回调中的量价判断

### 健康回调（量缩价稳）

```
特征：
- 回调过程中成交额逐步缩小（逐日递减或维持低位）
- 换手率降至趋势段平均的 50% 以下
- 回调K线实体小，影线不长

含义：回调是正常获利了结，非趋势反转
操作：在回调末端出现信号棒时入场
```

### 不健康回调（量增价跌）

```
特征：
- 回调过程中成交额放大（反向趋势棒放量）
- 出现放量大阴线
- 换手率持续走高

含义：主动抛售加剧，可能趋势反转
操作：观望，不入场做多
```

## 四、特殊量价形态

### 天量见天价

```
条件：单日成交额创近20日以上新高
- 若当日为长上影线或阴线 → 高概率见顶信号
- 若当日为大阳趋势棒且后续继续放量跟随 → 突破有效
判断关键：天量当日K线形态和次日走向
```

### 地量见地价

```
条件：成交额萎缩至近20日最低水平
含义：卖盘枯竭，市场极度冷清，可能即将变盘
操作：地量本身不入场，等待放量选择方向后跟随
典型位置：长期横盘区间末端、下降通道末端
```

### 涨停板量价

```
涨停缩量（封板量小、不开板）：
→ 筹码锁定良好，多方强势控盘，持续看多

涨停放量（封板量大、反复开板）：
→ 多空分歧大，买入需谨慎
→ 若是突破K涨停放量，仍视为有效突破，关注次日走向

跌停后缩量：
→ 恐慌性抛售后无人接盘，短期继续看空
→ 跌停放量打开后企稳 → 可能为恐慌底，等信号棒
```

### 缩量小阴线

```
- 出现在区间下沿：卖压枯竭，可能反弹
- 出现在上升通道回调中：健康回调的典型表现
- 连续多根缩量小阴线后出现放量阳线 → 回调结束信号
```

## 五、成交额流动性参考（A股）

| 日均成交额 | 流动性评级 | 操作建议 |
|-----------|-----------|----------|
| < 5000万 | 差 | 避免交易，滑点风险大 |
| 5000万 - 1亿 | 一般 | 仅轻仓参与（风险 0.5%） |
| 1亿 - 5亿 | 良好 | 正常交易 |
| > 5亿 | 优秀 | 适合各种策略 |

**注意**：成交额评估应基于近20日平均值，避免单日异常值干扰。

## 六、量价分析在各周期中的应用

| 市场周期 | 量价要点 |
|----------|----------|
| 交易区间 | 区间内缩量运行为正常；放量但未突破 = 多空分歧，继续区间 |
| 突破 | 放量突破是基本要求；缩量突破假突破概率极高 |
| 窄通道 | 顺势放量、回调缩量 = 趋势健康 |
| 宽通道 | 回调放量增加 = 趋势减弱信号，可能演变为区间 |
| 趋势末端 | 量价背离（创新高/低但量能递减）= 力竭预警 |
