# 市场周期详细参考

## 周期演变总览

```
交易区间 → 假突破 → 仍然是区间 → 再假突破 → 突破
                                              ↓
                                         震荡区间 或 通道
                                              ↓
                                    窄通道 → 突破
                                    宽通道 → 震荡区间

特殊路径（缺口驱动）：
区间 → 跳空突破（缺口不回补） → 直接进入强通道
通道 → 力竭缺口（很快回补） → 趋势可能反转 → 新区间
```

## 一、交易区间 (Trading Range)

### 定义
多条K线重叠形成的区间，碰到区间上沿就下跌，碰到区间下沿就上涨。

### 特征识别
- K线实体较小，影线较长
- 频繁出现反向K线
- 价格多次测试相同的高点和低点
- 均线趋于平缓或交织
- 价格在支撑位和阻力位之间反复震荡

### 交易策略

| 项目 | 说明 |
|------|------|
| **入场条件** | 必须有失败或反向信号K |
| **操作方向** | 区间下沿做多，区间上沿卖出/减仓 |
| **盈亏比** | 1:1 或 1:2 |
| **止损** | 放在交易区间外 |

### 周期演变
```
区间 → 假突破 → 仍然是区间 → 再假突破 → 才可能形成突破
```

### 区间识别要点
```
有效区间需满足：
- 至少 2 次有效触及上沿 + 2 次有效触及下沿
- 上沿/下沿误差在 1-2% 以内
- 区间持续时间至少 5 根以上K线

区间上沿：最近几根K线高点的水平阻力位
区间下沿：最近几根K线低点的水平支撑位
```

### 区间内禁止操作
```
❌ 不要在区间内顺势追涨（价格在区间上半部分时买入）
❌ 不要在区间内顺势杀跌（价格在区间下半部分时卖出）
❌ 不要在没有信号K的情况下入场
```

## 二、突破 (Breakout)

### 定义
价格强势突破交易区间，有好的信号K，收盘实体收在区间一半以上，并有跟随阳线。

### 有效突破 vs 假突破

| 特征 | 有效突破 | 假突破 |
|------|----------|--------|
| K线实体 | 大，影线短 | 小，影线明显 |
| 收盘位置 | 明显超出区间边界 | 勉强超出或刚刚越过 |
| 跟随K | 有同向确认K | 下一根立刻收回 |
| 回调深度 | 浅（< 50%突破K） | 深（> 50%突破K） |

### 突破后的两种演变

```
突破后 → 演变成通道（强趋势）
   特征：价格持续创新高/低，回调有序，形成趋势线

突破后 → 演变成震荡区间（弱趋势）
   特征：突破后价格反复，形成新的横盘区间
```

### 测量移动 (Measured Move，MM)

```
公式：
多头突破目标 = 突破点 + (区间上沿 - 区间下沿)
空头突破目标 = 突破点 - (区间上沿 - 区间下沿)

示例：
区间: 30.0 - 35.0（高度 = 5.0）
多头突破点: 35.0
MM目标: 35.0 + 5.0 = 40.0
```

### AB=CD 回调入场计算

```
A = 突破前区间边界
B = 突破后最高点（多）/ 最低点（空）
C = 回调低点（多）/ 高点（空）= 入场区域
D = C + (B - A) = 目标位

特征：AB段 = CD段（等距）

示例（多头）：
A = 35.0（突破点）
B = 37.0（突破后高点）
C = 36.0（回调低点，入场）
D = 36.0 + (37.0 - 35.0) = 38.0（目标）
```

## 三、通道 (Channel)

### 定义
价格在两条趋势线内沿着趋势走。

### 通道类型详细对比

| 对比项 | 窄通道 | 宽通道 |
|--------|--------|--------|
| K线重叠 | < 30% | 30%-60% |
| 回调深度 | 极浅（1-3根K） | 较深（3-8根K） |
| 趋势强度 | 极强 | 中等 |
| 信号K要求 | 低（在边沿即可） | 高（需要明确信号） |
| 演变方向 | → 突破加速 | → 震荡区间 |

### 通道上下轨画法

```
上升通道：
- 下轨：连接各个回调低点（支撑线）
- 上轨：平行于下轨，穿过高点

下降通道：
- 上轨：连接各个反弹高点（阻力线）
- 下轨：平行于上轨，穿过低点

注意：趋势线需要至少 2 个点确认，第 3 个点验证
```

### 通道失效信号

```
以下情况说明通道可能结束：
⚠️ 价格有效突破通道线（不是假突破）
⚠️ 出现反向强趋势棒超过通道
⚠️ K线重叠度明显增加（从窄变宽）
⚠️ 通道线斜率改变（加速或减速）
⚠️ 出现明显的第二低高点（空头）或第二高低点（多头）
```

## 四、周期转换识别

### 区间 → 突破
```
信号：
1. 连续出现 2-3 根同向趋势棒
2. 收盘价有效突破区间边界（超过区间高度的50%）
3. 有跟随K确认
4. 回调浅且快
5. 量价配合：突破时成交额放大（超近5日均额1.5倍），缩量突破可信度低
```

### 突破 → 通道
```
信号：
1. 突破后价格持续沿趋势方向运动
2. 出现有序回调（每次回调后创新高/低）
3. 回调低点（多）/ 高点（空）逐步抬高/降低
4. 可以画出趋势线
```

### 通道 → 区间
```
信号：
1. 价格不再创新高/低
2. 出现明显反向趋势棒
3. 多次假突破失败
4. K线重叠度增加
5. 量价特征：通道末端放量但无法创新高/低（量价背离）
```

### 缺口驱动的周期转换

#### 跳空突破（最强突破形式）
```
特征：
- 开盘直接跳过区间边界，且当日不回补缺口
- 成交额大幅放量（通常 > 近5日均额 × 2）
- 直接确认突破有效，无需等跟随K
- 缺口底部/顶部成为最强支撑/阻力

操作：
- 跳空突破后回调至缺口上沿附近 → 做多信号
- 缺口不被回补的时间越长，支撑越强
```

#### 力竭缺口（反转预警）
```
特征：
- 通道末端出现跳空（通常是第三推末端）
- 跳空后 1-3 日内缺口被回补
- 成交额可能放大也可能萎缩
- 三推后的跳空高概率为力竭缺口

操作：
- 缺口回补后等待反向信号棒入场
- A股：力竭缺口出现时应减仓或设紧止损
- 力竭缺口 + 量价背离 = 高概率反转
```

## 五、常见错误与纠正

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 区间内追涨杀跌 | 高买低卖，损失 | 高抛低吸 |
| 没有信号K就入场 | 胜率降低 | 等待信号K确认 |
| 忽略周期判断 | 用错策略 | 先判断周期 |
| 假突破后立即入场 | 被套 | 等待二次确认 |
| 在通道中部入场 | 没有边沿优势 | 只在边沿入场 |
| 第一次突破就追入 | 假突破被套 | 等回调或再次确认 |
