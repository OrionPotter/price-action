# 入场模式详细参考

### 第二分型（2L / 2H）——最高优先

**做多 2L（Higher Low 2）**
1. 确认上升趋势（高高低低结构）
2. 第一次回调形成 HL1，反弹创新高
3. 第二次回调形成 HL2（HL2 > HL1）
4. HL2 处出现多头信号棒
5. 突破信号K高点时入场做多
- 止损：HL2 低点下方 1 跳
- 目标1：前高 / 目标2：测量移动 MM

**做空 2H（Lower High 2）**

> ⚠️ A股提示：2H 做空模式不可直接交易，但识别它有助于判断持仓风险和减仓时机。出现 2H 结构时应考虑卖出/减仓。

1. 确认下降趋势（低低高高反向结构）
2. 第一次反弹形成 LH1，下跌创新低
3. 第二次反弹形成 LH2（LH2 < LH1）
4. LH2 处出现空头信号棒
5. 跌破信号K低点时确认做空信号（A股：减仓/卖出）
- 止损：LH2 高点上方 1 跳
- 目标1：前低 / 目标2：测量移动 MM

### 50% 回调入场

- 测量最近一段趋势波（起点→终点），取50%位
- 误差范围：40%～60%均有效
- **必须等信号棒出现**，不可仅凭价格到位就入场
- 最佳组合：50%位 + 支撑阻力位 + EMA20 三者重叠
- 止损：回调低点/高点外 1 跳
- 盈亏比目标：约 2:1（风险=50%段，收益=100%段）

回调失效条件：
- 回调超过前波段 70% 以上 → 趋势可能反转
- 1-2 根大K快速打穿50% → 考虑反转而非回调

---

### EMA20 入场

**强趋势中的回测入场**
- EMA20 持续上斜：回调轻触EMA20，出现多头信号棒，突破信号K高点入场
- EMA20 持续下斜：反弹轻触EMA20，出现空头信号棒，跌破信号K低点入场
- 止损：信号K极值外 1 跳

**关键概念：**
- EMA Gap Bar：整根K（含影线）未触及EMA20，之后回测时信号更强
- EMA20 走平 = 区间状态，此时EMA20参考价值低，改用区间边沿逻辑
- 斜率 > 45° = 强趋势；接近水平 = 区间；反向倾斜 = 可能反转
- 价格穿越EMA20后 1-3 根K无法离开 = 区间磁吸效应

### 三推模式（Three Pushes / Wedge）

**三推做空（上涨三推）**

> ⚠️ A股提示：上涨三推做空不可直接交易，但识别它是重要的卖出/减仓信号。

- 三个依次抬高的高点 P1 < P2 < P3，每段涨幅递减
- P3 处出现力竭信号（上影线、假突破、动能背离）
- 跌破P3信号K低点确认做空信号（A股：减仓/卖出）
- 止损：P3高点上方 1 跳
- 目标1：P2附近 / 目标2：P1附近（测量移动）

**三推做多（下跌三推）**
- 三个依次降低的低点 P1 > P2 > P3，每段跌幅递减
- P3 处出现力竭信号（下影线、假突破、动能背离）
- 突破P3信号K高点入场做多
- 止损：P3低点下方 1 跳
- 目标1：P2附近 / 目标2：P1附近

**三推进阶要点：**
- 最佳形态：三段推进K线根数大致相等 + 收敛楔形通道
- 最强信号：第三推出现假突破后立即反向（"假突破三推"）
- 三推失败：第三推超出前推1.5倍幅度 → 顺势信号而非反转

---

### 反转入场

**前提条件（缺一不可）：**
1. 趋势过度延伸：连续趋势棒、价格远离EMA20
2. 力竭信号：三推完成、假突破、反向大K吞噬
3. 信号K质量高：实体大、影线小
4. 至少信号棒 + 确认K，不可单根K反转入场

**看涨反转（底部）：**
- 高概率信号：三推下跌+假突破 / 多头外包柱 / 双底 / 放量大阳K
- 入场：突破反转信号K高点
- 止损：反转低点下方 1-2 跳
- 目标1：50%回撤位 / 目标2：前期LH1附近

**看跌反转（顶部）：**

> ⚠️ A股提示：看跌反转不可做空，但识别它是重要的卖出/清仓信号。

- 高概率信号：三推上涨+假突破 / 空头外包柱 / 双顶 / 放量大阴K
- 确认方式：跌破反转信号K低点（A股：卖出/清仓）
- 止损（如持仓）：反转高点上方 1-2 跳
- 目标1：50%回撤位 / 目标2：前期HL1附近

---

### 反弹入场（保守模式）

- 适用场景：价格触及支撑/阻力位，区间内或趋势回调中的短线机会
- 做多：支撑位 + 多头信号棒（下影线、外包柱） → 突破信号K高点
- 卖出/减仓：阻力位 + 空头信号棒（上影线、外包柱） → 跌破信号K低点时确认阻力有效
- 止损：支撑/阻力位外 1 跳
- 目标：区间中轴（保守）或区间另一侧（激进）
- **注意：反弹目标比反转小，不追大行情**

---

### 假突破反向入场

假突破特征：
- 突破K收盘未超出区间边界50%以上
- 突破K有明显反向影线
- 下一根K立刻收回区间内

操作：
- 多头假突破失败 → 卖出/减仓信号（A股不做空），假突破K低点被跌破时确认
- 空头假突破失败 → 做多，入场：假突破K高点被突破时
- 止损：假突破K极值外 / 目标：区间另一侧

---

### 突破入场

**回调入场（推荐）：**
- 有效突破后等待回调
- 回调质量要求：深度<50% + 1-3根K + K线有序不重叠 + 无反向趋势棒
- AB=CD 目标：D = C + (B-A)

**收盘入场（激进，需满足3条以上）：**
- 突破K实体>60% / 收盘明显超出区间 / 无反向影线 / 连续2-3根同向K / 区间多次假突破后

## 信号棒判断标准

**强多头信号棒：**
- 大阳K实体，收盘接近K线高点
- 下影线长，上影线短或无
- 吞噬/外包前一根或多根阴K
- 实体占总高度 > 60%

**强空头信号棒：**
- 大阴K实体，收盘接近K线低点
- 上影线长，下影线短或无
- 吞噬/外包前一根或多根阳K
- 实体占总高度 > 60%

**弱信号（谨慎）：**
- 十字星 / 蜡烛身很小
- 上下影线都很长（犹豫K）
- 收盘位于K线中部

---

## 回调质量判断

| 质量 | 特征 | 操作建议 |
|------|------|----------|
| 优质 | 有序不重叠 + 深度<50% + 无反向趋势棒 | 信号K出现即可入场 |
| 一般 | 偶有反向趋势棒 + 深度50-65% + 稍重叠 | 等待更明确信号K |
| 劣质 | 反向趋势棒群 + 深度>70% + 打穿EMA20 | 考虑反转而非回调 |

---

## 不入场情况（观望）

以下情况不入场，宁可错过：
- 价格在区间中部（无边沿优势）
- 趋势棒后直接追入（等回调）
- 信号棒后无确认K（等确认）
- 区间第一次测试边沿（等第二次或信号K）
- 假突破后立即反向入场（等确认K）
- 多空信号同时出现（不同周期冲突）
- 50%回调到位但无信号棒（等信号K）
- EMA20走平区间状态（改用区间逻辑）
- 三推完成但无力竭确认K（等反向K）
- 反转信号出现在趋势中段（逆势风险极高）
