# 风险管理详细参考

## 一、仓位计算

### 基础公式

```
仓位（股数）= (总资金 × 单笔风险%) ÷ (入场价 - 止损价)

示例：
总资金：100,000元
单笔风险：1%（即 1,000元）
入场价：10.50元
止损价：9.80元
止损幅度：0.70元/股

仓位 = 1,000 ÷ 0.70 = 1,428 股（取整为1400股）
```

### 风险控制表

| 风险比例 | 建议场景 | 说明 |
|----------|----------|------|
| 0.5% | 信号不确定 | 保守，信号较弱时用 |
| 1.0% | 常规入场 | 推荐默认值 |
| 1.5% | 高概率信号 | 如第二分型+强信号棒 |
| 2.0% | 极高把握 | 谨慎使用 |

**原则：单笔风险不超过总资金 2%**

## 二、止损设置

### 止损位选择原则

| 场景 | 止损位 |
|------|--------|
| 区间交易 | 区间边界外 1-2% |
| 突破入场 | 突破K起点（低点）外 1 跳 |
| 通道入场 | 通道线外（或前一个回调极值） |
| 第二分型 | 分型低点（多）/ 高点（空）外 1 跳 |

### 止损失效原则

```
止损被触发 = 判断失误，立刻出场，不要犹豫

常见错误：
❌ 止损被触发后"再等等"
❌ 移动止损扩大风险
❌ 补仓摊低成本
✅ 触及止损 → 立刻执行 → 重新评估市场
```

### 止损管理阶段（持仓过程中）

```
1. 入场时：信号K极值外 1 跳（初始止损）
2. 盈利达 0.5:1 时：移至保本价
3. 第一目标达到后：第一仓平仓，其余仓止损移至入场价
4. 趋势延续中：每根K收盘后移动止损至前K极值（状态止盈）
5. 出现反向信号时：主动平仓，不等止损触及
```

## 三、止盈策略

### 策略一：目标位止盈（适合区间/突破）

```
区间交易：
- 第一目标：区间中轴（盈亏比约 1:1，可出一半）
- 第二目标：区间另一侧（盈亏比约 1:2，剩余全出）

突破交易：
- 第一目标：测量移动 MM（= 突破点 + 区间高度）
- 第二目标：MM 的 1.5-2 倍延伸
```

### 策略二：状态止盈（适合通道/趋势）

```
持续持有，直到出现以下信号才出场：
- 出现反向趋势棒
- 通道趋势线被有效突破
- 出现明显的假突破信号
- 连续出现信号棒但无法创新高/低

优势：可以在强趋势中持有更长时间
劣势：可能回吐部分利润
```

### 策略三：分批止盈（推荐）

```
第一批（1/2仓）：
→ 到达第一目标时止盈，保住基本盈利

第二批（剩余）：
→ 移动止损保护，跟随趋势直到状态止盈

好处：
✅ 锁定部分利润，减少心理压力
✅ 保留趋势延伸的机会
✅ 平衡"太早出场"和"回吐利润"的矛盾
```

### 全部平仓触发条件

```
出现以下任一情况，应考虑全部平仓：
- 出现反向趋势棒群（连续 2-3 根反向大实体K线）
- 三推完成（力竭信号）
- 大K穿越EMA20并继续延伸
- 假突破 + 确认K反向信号
- 量价背离：价格创新高但成交额明显萎缩
```

## 四、盈亏比参考

| 周期 | 最低盈亏比 | 推荐盈亏比 | 说明 |
|------|------------|------------|------|
| 交易区间 | 1:1 | 1:2 | 区间空间有限 |
| 突破 | 1:2 | 1:3 | MM通常是区间高度 |
| 窄通道 | 1:2 | 1:3+ | 趋势持续时盈利大 |
| 宽通道 | 1:1.5 | 1:2 | 回调多，空间受限 |

## 五、连续亏损处理

```
触发条件：连续亏损 3 笔

处理方式：
1. 立刻停止交易，休息至少1天
2. 复盘每笔亏损：
   - 是执行问题？（没按计划操作）
   - 是判断问题？（市场读错了）
   - 是策略问题？（策略不适合当前市场）
3. 每日风险上限：不超过总资金 5%
4. 达到日亏损上限 → 当日停止交易

常见原因：
- 在区间中部追涨杀跌
- 没有等到信号棒就入场
- 忽略大周期方向只看小周期
- 止损设置过紧
```

## 六、A股特殊注意事项

| 项目 | A股特殊情况 | 应对 |
|------|------------|------|
| 涨跌停 | 主板10%、创业板/科创板20%、ST股5% | 止损不能超过当日极值；涨停K不作为正常信号棒分析 |
| T+1 | 当日买入不能当日卖出 | 止损执行延迟一天，需扩大预期风险 |
| 流动性 | 小盘股流动性差 | 优先选择日均成交额 > 1亿的个股（详见下方阈值表） |
| 板块联动 | 同板块个股走势相关 | 避免同时持有同板块多只 |
| 消息面 | 政策、业绩影响大 | 重大公告前谨慎持仓 |

### 流动性筛选标准

| 日均成交额 | 流动性评级 | 操作建议 |
|-----------|-----------|----------|
| < 5000万 | 差 | 避免交易，滑点风险大 |
| 5000万 - 1亿 | 一般 | 仅轻仓参与（风险 0.5%） |
| 1亿 - 5亿 | 良好 | 正常交易 |
| > 5亿 | 优秀 | 适合各种策略 |

> 成交额评估应基于近20日平均值，避免单日异常值干扰。详见 `references/volume.md`。
